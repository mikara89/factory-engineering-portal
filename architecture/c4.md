# C4 architecture views

The diagrams use C4 levels to show system context, containers, and components. The named containers and components describe logical boundaries. They are not all separate hosted services.

The Factory color legend is shown in the [architecture overview](overview.md#color-legend). The public portal remains outside the trusted engineering execution flow.

Containers and components show their technology in brackets. A dashed frame marks a system or container boundary.

## System context

```kroki-c4plantuml
@startuml
!include <C4/C4_Container>
LAYOUT_TOP_DOWN()
skinparam defaultFontName Verdana
HIDE_STEREOTYPE()

AddElementTag("source", $bgColor="#dbeafe", $fontColor="#0f172a", $borderColor="#2563eb", $legendText="work source")
AddElementTag("control", $bgColor="#ede9fe", $fontColor="#1f2937", $borderColor="#7c3aed", $legendText="trusted control")
AddElementTag("agent", $bgColor="#ffedd5", $fontColor="#431407", $borderColor="#ea580c", $legendText="untrusted execution")
AddElementTag("verify", $bgColor="#dcfce7", $fontColor="#052e16", $borderColor="#16a34a", $legendText="validation and verification")
AddElementTag("publish", $bgColor="#fee2e2", $fontColor="#450a0a", $borderColor="#dc2626", $legendText="privileged publication")
AddElementTag("infra", $bgColor="#e5e7eb", $fontColor="#111827", $borderColor="#6b7280", $legendText="infrastructure")
AddElementTag("human", $bgColor="#fef3c7", $fontColor="#111827", $borderColor="#d97706", $legendText="human review")
UpdateBoundaryStyle($fontColor="#334155", $borderColor="#64748b")
UpdateRelStyle($lineColor="#475569", $textColor="#334155")

title Factory Engineering system context

Person(engineer, "Engineer", "Defines work and reviews engineering proposals", $tags="human")
System_Boundary(factory, "Factory Engineering") {
    System(product, "Factory Engineering workflow", "Governs work, agent execution, verification, and engineering draft publication", $tags="control")
}
System_Ext(github, "GitHub", "Hosts repositories, Actions, pull requests, and Pages", $tags="infra")
System_Ext(model, "Model provider", "Provides model responses through the trusted broker", $tags="agent")
System_Ext(portal, "Proposed public portal", "Will serve reviewed documentation as a static site", $tags="infra")

Rel(engineer, product, "Submits or reviews engineering work")
Rel(product, github, "Uses repositories and Actions")
Rel(product, model, "Sends approved requests through the broker")
Rel(engineer, portal, "Reads public documentation")
Rel(product, portal, "Proposes reviewed public content through a draft PR")
Rel(portal, github, "Hosted with GitHub Pages")

Lay_R(model, portal)

@enduml
```

## Container view

```kroki-c4plantuml
@startuml
!include <C4/C4_Container>
LAYOUT_TOP_DOWN()
skinparam defaultFontName Verdana
HIDE_STEREOTYPE()

AddElementTag("source", $bgColor="#dbeafe", $fontColor="#0f172a", $borderColor="#2563eb", $legendText="work source")
AddElementTag("control", $bgColor="#ede9fe", $fontColor="#1f2937", $borderColor="#7c3aed", $legendText="trusted control")
AddElementTag("agent", $bgColor="#ffedd5", $fontColor="#431407", $borderColor="#ea580c", $legendText="untrusted execution")
AddElementTag("verify", $bgColor="#dcfce7", $fontColor="#052e16", $borderColor="#16a34a", $legendText="validation and verification")
AddElementTag("publish", $bgColor="#fee2e2", $fontColor="#450a0a", $borderColor="#dc2626", $legendText="privileged publication")

UpdateBoundaryStyle($fontColor="#334155", $borderColor="#64748b")
UpdateRelStyle($lineColor="#475569", $textColor="#334155")

title Engineering and public documentation containers

Person(engineer, "Engineer", "Reviews engineering and content proposals", $tags="human")
System_Boundary(factory, "Factory Engineering") {
    Container(productRepo, "Product repository", "Private GitHub repository", "Product code and reviewed public content source", $tags="source")
    Container(controlRepo, "Control repository", "Private GitHub repository", "Trusted workflows, approvals, and durable control state", $tags="control")
    Container(engineeringActions, "Engineering Actions", "GitHub Actions", "Runs the engineering workflow with role-specific jobs", $tags="control")
    Container(sandbox, "Agent sandbox", "Disposable container", "Runs untrusted agent tool commands", $tags="agent")
    Container(verifier, "Protected verifier", "Separate workflow job", "Checks an exact candidate with protected tests", $tags="verify")
    Container(productPublisher, "Engineering publisher", "Scoped credentials", "Creates an authorized engineering draft PR", $tags="publish")
    Container(portalProposal, "Portal proposal workflow", "Manual GitHub Actions workflow", "Validates allowlisted content and prepares a portal draft PR", $tags="infra")
}
System_Ext(model, "Model provider", "External model endpoint", $tags="agent")
System_Ext(github, "GitHub", "Hosts repositories, Actions, pull requests, and Pages", $tags="infra")
System_Ext(portal, "Proposed public portal", "Static GitHub Pages site", $tags="infra")

Rel(engineer, productRepo, "Creates and reviews product changes")
Rel_D(productRepo, engineeringActions, "Starts reviewed engineering workflows")
Rel_D(controlRepo, engineeringActions, "Supplies trusted workflow and state inputs")
Rel(engineeringActions, sandbox, "Starts bounded agent execution")
Rel(engineeringActions, model, "Requests model output through the broker")
Rel(engineeringActions, verifier, "Submits immutable candidate")
Rel(verifier, productPublisher, "Supplies verified result and evidence")
Rel_U(productPublisher, productRepo, "Creates engineering draft PR")
Rel(productRepo, portalProposal, "Owner starts from an exact reviewed commit")
Rel(portalProposal, portal, "Creates a portal draft PR with portal-only access")
Rel(engineer, portal, "Reads public documentation")
Rel(portal, github, "Hosted with GitHub Pages")

Lay_R(controlRepo, productRepo)

@enduml
```

The portal proposal workflow does not read the control repository. It has no connection to engineering execution.

## Component view: portal proposal workflow

```kroki-c4plantuml
@startuml
!include <C4/C4_Component>
LAYOUT_TOP_DOWN()
skinparam defaultFontName Verdana
HIDE_STEREOTYPE()

AddElementTag("source", $bgColor="#dbeafe", $fontColor="#0f172a", $borderColor="#2563eb", $legendText="work source")
AddElementTag("control", $bgColor="#ede9fe", $fontColor="#1f2937", $borderColor="#7c3aed", $legendText="trusted control")
AddElementTag("agent", $bgColor="#ffedd5", $fontColor="#431407", $borderColor="#ea580c", $legendText="untrusted execution")
AddElementTag("verify", $bgColor="#dcfce7", $fontColor="#052e16", $borderColor="#16a34a", $legendText="validation and verification")
AddElementTag("publish", $bgColor="#fee2e2", $fontColor="#450a0a", $borderColor="#dc2626", $legendText="privileged publication")
AddElementTag("infra", $bgColor="#e5e7eb", $fontColor="#111827", $borderColor="#6b7280", $legendText="infrastructure")
AddElementTag("human", $bgColor="#fef3c7", $fontColor="#111827", $borderColor="#d97706", $legendText="human review")
UpdateBoundaryStyle($fontColor="#334155", $borderColor="#64748b")
UpdateRelStyle($lineColor="#475569", $textColor="#334155")

title Manual public content proposal components

Container(source, "Product repository", "Private GitHub repository", "Reviewed public content and workflow source", $tags="source")
Container(control, "Control repository", "Private GitHub repository", "Trusted engineering state; not available to this workflow", $tags="control")
Container(portal, "Portal repository", "Public GitHub repository", "Static site source and reviewed update branches", $tags="infra")

Container_Boundary(proposal, "Product repository · manual proposal workflow") {
    Component(commitCheck, "Source commit check", "Trusted workflow", "Requires the exact reviewed default-branch commit", $tags="infra")
    Component(allowlist, "Public content validator", "Python", "Rejects unexpected paths and unsupported content", $tags="infra")
    Component(preparer, "Deterministic update preparer", "Python", "Copies only approved content and derives stable identity", $tags="infra")
    Component(reconciler, "Duplicate and conflict checks", "GitHub API", "Reconciles matching proposals and stops on uncertainty", $tags="infra")
    Component(app, "Portal publisher App", "Portal-only installation", "Creates a branch and draft PR", $tags="publish")
}

Rel(source, commitCheck, "Manual dispatch at reviewed commit")
Rel(commitCheck, allowlist, "Passes exact source revision")
Rel(allowlist, preparer, "Passes validated content")
Rel(preparer, reconciler, "Passes deterministic identity and file set")
Rel(reconciler, app, "Allows one write only when state is clear")
Rel(app, portal, "Creates portal branch and draft PR")

Lay_R(source, control)

@enduml
```

The control repository is shown to make the boundary clear. The portal proposal workflow has no relationship to it. The portal cannot authorize work or write back to a Factory repository.
