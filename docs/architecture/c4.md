# C4 architecture views

The diagrams use C4 levels to show system context, containers, and components. The named containers and components describe logical boundaries. They are not all separate hosted services.

The Factory color legend is shown in the [architecture overview](overview.md#color-legend). The public portal remains outside the trusted engineering execution flow.

## System context

```mermaid
C4Context
    title Factory Engineering system context
    Person(engineer, "Engineer", "Defines work and reviews engineering proposals")
    System_Boundary(factory, "Factory Engineering") {
        System(product, "Factory Engineering workflow", "Governs work, agent execution, verification, and engineering draft publication")
    }
    System_Ext(github, "GitHub", "Hosts repositories, Actions, pull requests, and Pages")
    System_Ext(model, "Model provider", "Provides model responses through the trusted broker")
    System_Ext(portal, "Proposed public portal", "Will serve reviewed documentation as a static site")

    Rel(engineer, product, "Submits or reviews engineering work")
    Rel(product, github, "Uses repositories and Actions")
    Rel(product, model, "Sends approved requests through the broker")
    Rel(engineer, portal, "Reads public documentation")
    Rel(product, portal, "Proposes reviewed public content through a draft PR")
    Rel(portal, github, "Hosted with GitHub Pages")

    UpdateElementStyle(engineer, "#fef3c7", "#111827", "#d97706")
    UpdateElementStyle(product, "#ede9fe", "#1f2937", "#7c3aed")
    UpdateElementStyle(github, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(portal, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(model, "#ffedd5", "#431407", "#ea5800")
```

## Container view

```mermaid
C4Container
    title Engineering and public documentation containers
    Person(engineer, "Engineer", "Reviews engineering and content proposals")
    System_Boundary(factory, "Factory Engineering") {
        Container(productRepo, "Product repository", "Private GitHub repository", "Product code and reviewed public content source")
        Container(controlRepo, "Control repository", "Private GitHub repository", "Trusted workflows, approvals, and durable control state")
        Container(engineeringActions, "Engineering Actions", "GitHub Actions", "Runs the engineering workflow with role-specific jobs")
        Container(sandbox, "Agent sandbox", "Disposable container", "Runs untrusted agent tool commands")
        Container(verifier, "Protected verifier", "Separate workflow job", "Checks an exact candidate with protected tests")
        Container(productPublisher, "Engineering publisher", "Scoped credentials", "Creates an authorized engineering draft PR")
        Container(portalProposal, "Portal proposal workflow", "Manual GitHub Actions workflow", "Validates allowlisted content and prepares a portal draft PR")
    }
    System_Ext(model, "Model provider", "External model endpoint")
    System_Ext(github, "GitHub", "Hosts repositories, Actions, pull requests, and Pages")
    System_Ext(portal, "Proposed public portal", "Static GitHub Pages site")

    Rel(engineer, productRepo, "Creates and reviews product changes")
    Rel(productRepo, engineeringActions, "Starts reviewed engineering workflows")
    Rel(controlRepo, engineeringActions, "Supplies trusted workflow and state inputs")
    Rel(engineeringActions, sandbox, "Starts bounded agent execution")
    Rel(engineeringActions, model, "Requests model output through the broker")
    Rel(engineeringActions, verifier, "Submits immutable candidate")
    Rel(verifier, productPublisher, "Supplies verified result and evidence")
    Rel(productPublisher, productRepo, "Creates engineering draft PR")
    Rel(productRepo, portalProposal, "Owner starts from an exact reviewed commit")
    Rel(portalProposal, portal, "Creates a portal draft PR with portal-only access")
    Rel(engineer, portal, "Reads public documentation")
    Rel(portal, github, "Hosted with GitHub Pages")

    UpdateElementStyle(engineer, "#fef3c7", "#111827", "#d97706")
    UpdateElementStyle(productRepo, "#dbeafe", "#0f172a", "#2563eb")
    UpdateElementStyle(controlRepo, "#ede9fe", "#1f2937", "#7c3aed")
    UpdateElementStyle(engineeringActions, "#ede9fe", "#1f2937", "#7c3aed")
    UpdateElementStyle(sandbox, "#ffedd5", "#431407", "#ea5800")
    UpdateElementStyle(verifier, "#dcfce7", "#052e16", "#16a34a")
    UpdateElementStyle(productPublisher, "#fee2e2", "#450a0a", "#dc2626")
    UpdateElementStyle(portalProposal, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(portal, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(model, "#ffedd5", "#431407", "#ea5800")
```

The portal proposal workflow does not read the control repository. It has no connection to engineering execution.

## Component view: portal proposal workflow

```mermaid
C4Component
    title Manual public content proposal components
    Container(source, "Product repository", "Private GitHub repository", "Reviewed public content and workflow source")
    Container(control, "Control repository", "Private GitHub repository", "Trusted engineering state; not available to this workflow")
    Container(portal, "Portal repository", "Proposed public GitHub repository", "Static site source and reviewed update branches")

    Container_Boundary(proposal, "Product repository · manual proposal workflow") {
        Component(commitCheck, "Source commit check", "Trusted workflow", "Requires the exact reviewed default-branch commit")
        Component(allowlist, "Public content validator", "Python", "Rejects unexpected paths and unsupported content")
        Component(preparer, "Deterministic update preparer", "Python", "Copies only approved content and derives stable identity")
        Component(reconciler, "Duplicate and conflict checks", "GitHub API", "Reconciles matching proposals and stops on uncertainty")
        Component(app, "Portal publisher App", "Portal-only installation", "Creates a branch and draft PR")
    }

    Rel(source, commitCheck, "Manual dispatch at reviewed commit")
    Rel(commitCheck, allowlist, "Passes exact source revision")
    Rel(allowlist, preparer, "Passes validated content")
    Rel(preparer, reconciler, "Passes deterministic identity and file set")
    Rel(reconciler, app, "Allows one write only when state is clear")
    Rel(app, portal, "Creates portal branch and draft PR")

    UpdateElementStyle(source, "#dbeafe", "#0f172a", "#2563eb")
    UpdateElementStyle(control, "#ede9fe", "#1f2937", "#7c3aed")
    UpdateElementStyle(portal, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(commitCheck, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(allowlist, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(preparer, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(reconciler, "#e5e7eb", "#111827", "#6b7280")
    UpdateElementStyle(app, "#fee2e2", "#450a0a", "#dc2626")
```

The control repository is shown to make the boundary clear. The portal proposal workflow has no relationship to it. The portal cannot authorize work or write back to a Factory repository.

Mermaid documents C4 diagrams as experimental. The local and deployed site builds must render these diagrams before publication.
